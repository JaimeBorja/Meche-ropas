Seguridad y Copias de Respaldo

Información importante sobre tus datos:
Esta aplicación guarda toda la información directamente en el almacenamiento local (localStorage) de este navegador y dispositivo. Los datos no se envían a ningún servidor externo.

Recomendación fundamental: Descarga una copia de seguridad en formato JSON periódicamente (por ejemplo, al final de cada semana o después de registrar varias ventas/cobros) y guárdala en tu iPhone (Archivos / iCloud), computadora o envíatela por correo/WhatsApp. Así podrás restaurar tus datos fácilmente si cambias de teléfono o limpias el historial del navegador.

1. Descargar Copia de Seguridad

Genera un archivo .json con todos tus clientes, deudas e historial completo de pagos.

2. Restaurar Copia de Seguridad

Selecciona un archivo .json exportado previamente para recuperar toda tu información.
